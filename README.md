# Project 1: *Manuscript*

Demo/template for our [first projects](https://typography-interaction-2627.github.io/project/1/).

> **Students will choose a seminal design text from [readings.design](https://readings.design), read and respond to it, and typeset their selection and reply together.**
>
> The goal of this project is to hone your basic skills in typography, focusing on expression, hierarchy, and form appropriate to a work. You will do this through exploration, trial and error, and responding to critical feedback. And then you will execute this typesetting in code, as a web page


> This project explores how written language can be communicated visually through the design of a web based article. The project experiments with how the content of an article can be transformed into visual elements, using typography and layout to visually communicate its ideas. And the design not just presenting the information as text, the design aims to help readers understand the article’s main points through visual experiences, showing how the visual form of words can influence how a message is read, interpreted, and understood.

>When I first started sketching, my designs were more cautious and less experimental. After I received feedback, I started looking more closely at the article's content and thinking about how its ideas could translate into visual elements. This process helped me gradually develop the design direction I used in the final website. While building the HTML, I also looked at the structure and layouts of other article-based websites for reference. This helped me think about how different parts of the webpage should be organized, such as where the footer should go and how to create a clearer hierarchy. I also considered how the structure and spacing of the page could create a better reading experience.

>When I started writing the HTML, I created a very basic structure for the page. However, after I began working on the CSS, I realized that the HTML structure did not have enough levels of hierarchy for me to style certain sentences or words separately. As I developed the CSS, I repeatedly went back to the HTML elements, how they are nested within one another, and how a webpage is built layer by layer, with each element creating a different level of structure and meaning.

>When I wrote the CSS, I did not organize my styles from broad to specific at the beginning, which resulted in a lot of repeated styling and made my CSS more complicated than it needed to be. After receiving feedback from the professor, I began reorganizing and simplifying my CSS. Through this process, I developed a better understanding of how CSS works as a system, especially how selectors and reusable styles can be organized to avoid unnecessary repetition.

>One of the things I want to remember from this project is how interactive elements can make a website more engaging. I especially enjoyed using elements such as 'details' and 'summary', as well as hover effects. I like how these small interactions allow readers to click, explore, and reveal information instead of simply reading a static page. They made the website feel more playful and interactive while still supporting the content.
